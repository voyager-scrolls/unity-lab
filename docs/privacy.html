unity-lab — Privacy Policy

Last updated: 2026-11-11

unity-lab is a private, personal software-development project operated by its sole developer (the owner of this GitHub account). This page explains what data the project touches and why.

What this application accesses

The project's local automation tooling (rclone) uses Google Drive API access with the developer's own Google account only, for the sole purpose of storing and retrieving the developer's own build artifacts, caches, and configuration files on the developer's own Drive.

What we do not do

  • We do not collect, read, transmit, or analyze any data from any other user.
  • We do not use analytics, advertising, or tracking of any kind.
  • We do not share data with third parties.
  • There are no other users: the OAuth client shown during authorization is restricted to the developer's own account and is used exclusively for this developer's automation.

Data storage

All data handled by this project resides in the developer's own Google Drive, the developer's own GitHub repositories, and the developer's own computers. No data is stored by third parties on the developer's behalf beyond those services' normal operation.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

Contact

Open an issue at github.com/voyager-scrolls/unity-lab.
